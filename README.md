## Суть проекта 
В данной работе исследуется зависимость валового регионального продукта (ВРП) от ключевых показателей человеческого ресурса (***Процент безработных, Доля городского населения, Процент населения с высшим образованием, Заболеваемость, Миграционный поток населения, Доля рабочей силы***) в регионах РФ. Основная цель — выявить, как инвестиции в образование, здравоохранение и науку влияют на экономический рост, и проверить, сохраняется ли эта зависимость при разделении регионов на группы.

Гипотезы:
o	Уровень безработицы оказывает статистически значимое отрицательное влияние на валовый региональный продукт (ВРП)
o	Существует структурный разрыв в уровне валового регионального продукта
o	Специализация на добыче полезных ископаемых является доминирующим фактором формирования ВРП, нивелирующим влияние других показателей человеческого капитала

## Ключевые этапы исследования 
1. Предварительная обработка
   - Анализ выбросов. Проверка данных на наличие экстремальных значений (аномалий), которые могли бы сместить оценки МНК.
   - Логарифмирование переменной. Переход к зависимой переменной ln(Y).
   - Корреляционный анализ. Построение матрицы для исключения факторов с высокой мультиколлинеарностью.
2. В рамках работы было последовательно разработано три типа спецификаций:
   **Модель 1. Базовая модель с ln(y)**
   - В baseline моделе была выявлена гетероскедастичность, был использован метод взвешенного МНК, что избавило от гетероскедастичности.
  
   **Модель 2. Базовая модель с дамми-переменной**
    - Введение фиктивной переменной для выделения сырьевых регионов. Для учета структурных особенностей экономики РФ, связанных с ресурсной рентой.

   **Модель 3. Построение обобщенной модели со структурными сдвигами на основе кластерного анализа**
    - Для учета неоднородности регионов был проведен многомерный кластерный анализ по трем факторам: Процент безработных, Доля городского населения, Процент населения с высшим образованием.
    - Были построены три частные регрессионные модели (по одной для каждого кластера) для оценки различий в коэффициентах.
    - Для определения того, можно ли объединить все регионы в одну общую модель, был проведен тест Чоу.
    - Результаты теста Чоу подтвердили структурную стабильность (отсутствие значимых различий в наклонах прямых регрессии). Это позволило сделать вывод, что механизмы влияния факторов на ВРП идентичны для всей выборки.
    - На основе результатов теста Чоу была разработана итоговая модель на объединенных данных, дополненная фиктивными переменными о принадлежности к кластеру
3. Проведенные тесты:
    - Тест Уайта. Проверка на гомоскедастичность остатков.
    $$H_0: D(\varepsilon) = const,$$ $$H_1: \widehat{\varepsilon^2} = \beta_0 + \sum_{j=1}^{m} \beta_j x_{ij} + \sum_{q=1}^{m} \sum_{p=1}^{m} \beta_{qp} x_{ip} x_{iq} + \delta_i$$
    - Тест Рамсея. Проверка на правильность функциональной формы (спецификации) модели и отсутствие пропущенных переменных. H_0: α_2 = ... = α_(m) = 0, H_1: ∃ α_i≠0,i=2,…,m.
    - Тест на нормальность остатков. Использование критериев Жака-Бера для подтверждения того, что ошибки распределены нормально (необходимо для надежности t-статистик). H_0: ε_i  ∈N (0,σ^2), H_1: ε_i  ∉N (0,σ^2) 
    - Тест Чоу. Проверка на наличие структурных сдвигов. Тест показал стабильность параметров регрессии для разных групп регионов, что обосновало использование единого уравнения с дамми-переменными вместо раздельных моделей.
    $$
    \begin{cases} 
    H_0: \beta_1 = \beta_2 = \dots = \beta_k = 0 \\
    H_1: \beta_j \neq 0, \text{ хотя бы для одного } j = 1, \dots, k 
    \end{cases}
    $$
    - Критерий качества Акаике. Сравнение моделей с помощью информационного критерия Акаике для выбора наиболее точной и лаконичной спецификации.
  
## Полученные модели и выбор наилучшей
### Сравнение моделей
| Модель | $R^2$ | AIC |
| :--- | :---: | :---: |
| **Базовая** <br> ln(Y)= -1,4183 - 0,0366 * X1+ 0,0121 * X2 + ε | 0,505 | 37,96 |
| **С дамми D1** <br> ln(y) = -1,4729 - 0,0321 * X1 + 0,0117 * X2 + 0,4454γ + ε | 0.549 | 26.09 |
| **Обобщенная** <br> ln(y) = -1,46 - 0,028 * X1 + 1,245 * X2 + 0,482γ - 0,356cl1 + 0,147cl2 + ε | 0.584 | 22.82 |

На основе представленных статистических результатов можно однозначно заключить, что обобщенная модель со структурными сдвигами на основе кластерного анализа с фиктивной переменной является существенно лучшей моделью для анализа исходных данных. Это заключение основано на сравнении ключевых критериев качества моделей по таблице. Во-первых, наиболее важный показатель для сравнения моделей – это критерий информационности Акаике (AIC), который строго наказывает за избыточное усложнение модели. У модели 3 значение AIC составляет 22.82, что ниже остальных. Во-вторых, объяснительная сила модели 3 также выше. Коэффициент детерминации R-квадрат для неё равен 0,584, это означает, что она объясняет около 58% вариации зависимой переменной, что выше остальных. Это прямо указывает на более высокую предсказательную способность третьей модели.

## Интерпретация модели
Трансформируем модель от логарифмической модели к мультипликативной. \
Итоговый вид модели: Y = 0,232 * 0,972 * X1 * 3,473 * X2 * 1,619γ * 0,701cl1 * 1,158cl2

Увеличение безработицы на 1% умножает ВРП на 0,972 (то есть снижает его на 2,8%). **Гипотеза 1 подтверждена.**
Увеличение показателя образования на единицу умножает ВРП в 3,473 раза (рост на 247%). *Фактор высшего образования (X2) демонстрирует максимально высокую значимость. Однако столь высокий коэффициент (1,245) свидетельствует о том, что данный фактор аккумулирует в себе совокупный эффект других институциональных преимуществ развитых регионов*
Если регион сырьевой (γ=1), его ВРП умножается на 1,619 (выше на 61,9%). **Гипотеза 3 подтверждена.**
Если регион относится к 1-му кластеру, его ВРП умножается на 0,701 (ниже на 29,9% от базового уровня). **Гипотеза 2 подтверждена.**
Если регион относится ко 2-му кластеру, его ВРП умножается на 1,158 (выше на 15,8% от базового уровня).
